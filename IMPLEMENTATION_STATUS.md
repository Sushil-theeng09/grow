## Status vocabulary

- **Proposed:** an idea under consideration; not approved for delivery.
- **Approved:** an accepted product requirement or decision.
- **In progress:** implementation is underway.
- **Implemented:** code is present, but acceptance validation may remain.
- **Tested:** implemented behavior has passed its stated acceptance checks.
- **Deferred:** intentionally postponed with a reason or dependency.

Backlog entries use these distinctions; a written requirement does not imply implementation.
