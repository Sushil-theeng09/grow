# Grow

Grow is envisioned as a complete personal learning and development ecosystem: a connected place to discover opportunities, set goals, learn, practice, assess skills, and track progress.

The repository is at the documentation and discovery stage. No application behavior, technology stack, or production architecture has been implemented or selected yet.
